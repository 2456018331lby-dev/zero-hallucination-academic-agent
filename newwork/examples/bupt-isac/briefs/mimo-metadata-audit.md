# 子任务简报 · 论文元数据抽取（规则明确的重复性劳动）

> 这是一份派发给 **MiMo Desktop** 的独立任务简报。执行者看不到协调方的对话，
> 因此所有路径、规则、输出格式与验收标准都在此写清。

## 角色

你是一名数据抽取工人。任务是把一批已经由程序从 PDF 抽出的纯文本文件，
规范化为一张元数据表格。**不需要理解论文内容，只需要按规则抽取。**

## 输入

目录（Windows 绝对路径）：

```
C:\Users\24560\Desktop\study\pidemo\newwork\examples\bupt-isac\work\pdftext
```

该目录下有 **11 个 `.txt` 文件**。每个文件是一篇论文的全文抽取结果，格式为：

```
<<<PAGE 1>>>
（第 1 页文本）
<<<PAGE 2>>>
（第 2 页文本）
...
```

## 对每个文件，抽取以下 5 项

| 字段 | 抽取规则 |
| :-- | :-- |
| 文件名 | 该 `.txt` 的文件名（含 `.txt`） |
| arXiv 编号 | 形如 `arXiv:2505.10306v1` 的字符串。通常出现在**第 1 页最顶部**（页眉）。若全文中找不到 → 写 `未找到` |
| 年份 | 取页眉里 arXiv 编号旁的日期中的年份，例如 `15 May 2025` → `2025`。若找不到 → 写 `未找到` |
| 标题 | 第 1 页最顶部的论文标题（可能跨 2–3 行，需要合并成一行）。不要包含作者、不要包含 `Abstract` |
| 页数 | 全文 `<<<PAGE n>>>` 标记中的最大 `n` |

## 输出格式（严格遵守）

只输出一张 Markdown 表格，表头**必须完全如下**，共 11 行数据：

```
| 序号 | 文件名 | arXiv编号 | 年份 | 标题 | 页数 |
| :--: | :-- | :-- | :--: | :-- | :--: |
```

表格之后，另起一行输出一句总计：`共 <N> 个文件，其中 arXiv 编号缺失 <M> 个。`

## 强制规则

1. **只读**：只读取上述目录下的 `.txt` 文件。
2. **不要创建、修改、删除任何文件**（不要在磁盘上写结果）。
3. **不要联网**。全部信息只来自这些文本文件。
4. **不要推测**：看不到的字段一律写 `未找到`，不要用常识补全。
5. 最终回复**只包含**那张表格和那一行总计，不要有任何额外解释、寒暄或前言。
