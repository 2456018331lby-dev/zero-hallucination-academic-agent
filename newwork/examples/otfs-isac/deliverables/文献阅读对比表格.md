| [04] | OFDM-ISAC 在高机动场景受子载波间干扰(ICI)制约；而已有 OTFS 雷达研究把 ISI/ICI 当作纯干扰丢弃，既未纳入信号模型也未加利用。 | 先推导显式含 ISI/ICI 的 MIMO-OTFS 雷达与通信信号模型；再给出基于广义似然比检验(GLRT)的多目标检测与时延-多普勒-角度三维估计算法，可同时抑制并利用 ISI/ICI；最后针对 discovery/track 两种模式提出自适应 ISAC 传输策略（discovery 用 delay-Doppler 复用，track 在空间域与 DD 域联合优化雷达 SNR 与可达速率的折中）。 | 首次在 MIMO-OTFS ISAC 中把 ISI/ICI 从「干扰」改造为可利用的结构（避免目标遮蔽、突破常规无模糊距离/速度上限）；提出 delay-Doppler (DD) multiplexing 概念以构造虚拟阵列；给出空间+DD 域的 ISAC 联合设计算法。 |

| [37] | 面向机载/空中通信网络这类极高多普勒场景，OTFS 波形在真实量级的多普勒下能否维持链路性能，缺乏系统性评估。 | 对 OTFS 调制在高多普勒机载网络中的 BER 性能做系统评估，变化物理层参数、DD 域 bin 数、直达信道与两径地反射信道模型，以及 MIMO 与 OTFS 结合形成的 MIMO-OTFS。 | 把「高机动」具体化为相对速度超过 1200 m/s、多普勒达 52–72 kHz 的机载场景，并给出多普勒 bin 数等参数的敏感性结论。 |
| [34] | OTFS 作为联合通信与雷达(JCR)波形的潜力尚未被充分挖掘，缺少与其他先进波形在同一框架下比较的统一表述。 | 用离散分数阶傅里叶变换(DFrFT)总结出统一矩阵(UM)表达，在此基础上提出 UM-OTFS 波形（预处理与 Heisenberg 变换阶段取相同分数阶参数，可通过改变分数阶退化为其他波形）；并给出三阶段感知参数估计（网格划分 + 粗估计 + 精估计）与基于 LU 分解的低复杂度分数阶 ZF/MMSE 均衡器。 | 统一矩阵框架把 OTFS 与多种先进波形纳入同一表述；分数阶 LU-ZF/MMSE 均衡达到对数线性复杂度且 BER 无退化。 |
| [20] | OTFS 信道估计若忽略多普勒斜视(Doppler squint effect, DSE)与网格失配，估计精度会明显下降。 | 在 DD 域采用嵌入式导频，基于含 DSE 的输入输出关系提出离网格(off-grid)稀疏贝叶斯学习(SBL)估计方案。 | 同时处理 DSE 与 off-grid 失配，弥补「忽略 DSE 或网格匹配」的两类方案的精度损失。 |
| [30] | 已有 OTFS 信道估计与均衡工作大多假设理想同步与理想信道估计；一旦存在残余帧定时偏移(frame timing offset, FTO)、载波频偏(CFO)与分数多普勒，DD 域信道矩阵结构随之改变，估计精度与复杂度都不再受控。 | 先建立含残余 FTO/CFO 的 CP-OTFS 完整信号模型并推导时域等效信道矩阵；用 DD 域嵌入式导频 + 能量门限 + 样条插值在时域估计信道，进而给出低复杂度块对角 LMMSE 均衡与 SIC 接收机（面向 LDPC 编码 CP-OTFS），并给出 OTFS 与 OFDM 的统一信号处理流程。 | 证明时域等效信道矩阵的结构不随多普勒取值改变、且比 DD 域矩阵更稀疏——分数多普勒下 H_DD 的非零元可达 N²N_e，而 H 恒为约 P 倍更稀疏；由此把估计与均衡放到时域，既免疫残余同步误差又把复杂度降低一个数量级；并给出 OTFS/OFDM 统一描述以支撑可重构空口。 |
| [35] | 相对 OFDM 的预处理/后处理复合描述，OTFS 缺少简洁、统一的数学刻画，导致其性质难以从第一原理看清。 | 基于离散 Zak 变换(DZT)给出 OTFS 的高效数字实现，并仅由 DZT 性质推导 DD 域输入输出关系与信道容量表达式。 | 用 DZT 提供比 OFDM 复合结构更简洁的 OTFS 统一描述；指出可通过 Nyquist 脉冲的 roll-off 控制时延域干扰、对子采样序列加窗控制多普勒域干扰。 |
| [38] | 各种 OTFS 变体的检测器性能与复杂度不一，缺少统一且低复杂度的检测方法。 | 推导所有 OTFS 变体的一般输入输出关系，提出低复杂度通用最大比合并(universal MRC)检测，并讨论复杂度与收敛性；进一步给出过扩展(overspread)信道的 DD 域输入输出关系。 | universal MRC 对所有 OTFS 变体性能一致；优于 LMMSE 检测（尤其高阶调制）；可扩展到过扩展信道。 |
| [23] | OTFS 虽在多普勒鲁棒性上有优势，但如何与现有 OFDM 系统兼容并走向标准化尚不清晰。 | 系统梳理 DD 域波形的根本优势，论证 OTFS 与现有 OFDM 下行/上行系统的兼容路径；给出 MU-MIMO-OTFS 预编码方案；讨论 DD-ISAC 的统一收发机设计与模糊函数特性。 | 提出面向标准化的部署路径与复杂度随信道维度线性增长的 MU-MIMO-OTFS 预编码；强调 DD-ISAC 通过设计基函数获得有利的模糊函数特性。 |
