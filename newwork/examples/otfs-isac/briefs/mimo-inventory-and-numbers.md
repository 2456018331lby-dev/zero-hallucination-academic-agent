## 任务 A：元数据盘点表

逐个 `.txt` 文件读取，输出**一张** Markdown 表格，每篇论文一行，列如下：

| 列 | 取法 |
| :-- | :-- |
| 文件名 | `.txt` 文件名去掉扩展名，原样照抄 |
| 标题 | 论文首页的最大标题，**原样照抄**（含大小写、连字符、副标题），不要翻译不要改写 |
| 第一作者 | 首页作者行里出现的第一个姓名 |
| 年份 | 首页或页脚标注的年份 |
| 刊物/会议 | 首页页眉或页脚出现的期刊名/会议名 |
| DOI | 首页出现的 DOI 字符串 |
| 页数 | 文中 `<<<PAGE n>>>` 的最大 n |

**取不到就写 `未标注`**，不要猜测、不要从标题推断、不要留空。

## 任务 B：带单位的定量声明罗列

对每个 `.txt`，把文中出现「数字 + 单位」的定量陈述句**原样抄出来**，列成一张 Markdown 表格：

| 论文编号 | 页码 | 原句 |
| :-- | :-- | :-- |

- 论文编号：文件名开头的 `[NN]`，如 `[04]`
- 页码：该句所属的 `<<<PAGE n>>>` 的 n
- 原句：**原样照抄英文原句**，最多 40 个单词，不要改写、不要翻译、不要截断成看不懂的片段

优先收录含以下单位的句子：`%`、`dB`、`dBm`、`GHz`、`MHz`、`kHz`、`m`、`cm`、`mm`、`km/h`、`ms`、`µs`、`ns`、`bit`、`km`。

**每篇最多 12 条。** 如果一篇有超过 12 条，选信息量最大的 12 条（优先含具体数值与对比结论的）。
