# 博士科研文献调研助手 (PhD Literature Survey Assistant)

专为博士生在读阶段快速了解新研究方向、准备组会精读汇报或学位论文开题文献综述设计的自动化调研 Agent 技能。
基于用户本地上传的论文全文或摘要，执行严格的学术文献摄取、多维矩阵提炼、深度学术综述与学术汇报幻灯片生成。

---

## 核心工作原则 (Core Principles)

1. **绝对忠实于本地文献 (Strict Grounding & Verification Gate)**：
   - 所有论述、数据、结论必须源自本地真实存在的文献（`./literature/`）。
   - 严禁编造或臆测任何作者、论文标题、数据集指标、SOTA 数值或消融结论。
   - **铁律**：产出的精读对比矩阵必须运行 `python scripts/verify_grounding.py <matrix_file> [--pdf-dir|--literature-dir <dir>]` 执行强依据物理校验（基于 PyMuPDF 真实打开物理 PDF、核验页码落在真实页数区间内、抽取指定页文本与论文特征词匹配）；若核验失败（存在未就绪文献、页码超出物理页数、或文本不吻合），矩阵直接作废重做，严禁用于正文写作！
2. **零幻觉与未知标记 ("文献未说明" Policy)**：
   - 若某篇文献未公开具体超参数、未报告某项消融实验、未说明基线设置或未给出代码链接，必须明确填写 **“文献未说明”**，切勿通过通用常识脑补。
3. **两阶段分流精读 (Two-Tier Screening)**：
   - 当本地论文总数超过 12 篇时，先进行全局快速通读（Title/Abstract/Intro/Conclusion），筛选出与核心课题最强相关的 **8-12 篇代表作进行深度精读**，其余文献作为背景或脉络参考。
4. **博士生组会学术深度 (PhD Academic Rigor)**：
   - 拒绝科普化、表面化描述。
   - 聚焦：**数学/理论建模动机**、**归纳偏置 (Inductive Bias)**、**核心创新与结构权衡 (Trade-offs)**、**实验对照组与统计有效性**、**方法的根本性缺陷与未解瓶颈**。

---

## 三大交付产物与双格式支持 (Three Core Deliverables & Dual Formats)

调用本技能时，按顺序完整产出以下核心产物（支持 Markdown 与标准 LaTeX 双版本）：

```
产物一：文献阅读对比表格 (Literature Comparison Matrix)
  ├── 15个标准学术维度字段，横向矩阵式对比 (Markdown)
  ├── LaTeX booktabs 标准三线表源码 (用于学术毕业论文/正文插入)
  └── GB/T 7714-2015 标准 BibTeX 数据库文件 (references.bib)

产物二：研究方向深度调研报告 (Direction Survey Report)
  └── 7大结构化章节，系统剖析问题本质、发展脉络、方法分类、重点精读、未解问题与博士切入点

产物三：组会/开题文献汇报幻灯片 (PhD Seminar Slide Deck)
  ├── 选项 A：Marp 格式 16:9 幻灯片 (适合快速 Markdown 预览与一键导出)
  └── 选项 B：LaTeX Beamer (ctexbeamer, 16:9, Metropolis/Madrid 主题，适合顶会/严谨答辩)
  └── 均配备演讲备注 (Presenter Notes)，辅助准备 15-20 分钟学术演讲
```


## 标准执行流水线 (Execution Pipeline)

### 第一阶段：本地文献发现与初筛 (Ingestion & Triage)
1. **扫描与提取**：
   - 扫描当前工作区或用户指定目录下的文献文件（支持 `.pdf`, `.md`, `.txt`）。
   - 可调用配套脚本：`scripts/scan_literature.py` 提取文献元数据（标题、作者、年份、摘要、关键词、章节结构）。
2. **通读与定级**：
   - 梳理文献清单，如果篇数 > 12 篇，根据引用影响力、技术代表性与核心课题相关度，遴选出 8-12 篇核心精读文献，并注明遴选理由。

---

### 第二阶段：制作 16 维文献阅读对比表格 (Comparative Matrix)

在产物输出或中间文档中，为每篇文献建立严格规范的 16 维对比表格。字段规范如下（详见 `references/table-template.md`）：

| 序号 | 字段名称 | 填写标准与学术要求 |
| :---: | :--- | :--- |
| 1 | **序号** | 连续编号 [1], [2], ... |
| 2 | **论文题目** | 英文原名（中文可加译名） |
| 3 | **作者** | 第一作者 et al.，注明通讯作者或主要实验室/团队 |
| 4 | **年份** | 发表年份（如 2024） |
| 5 | **会议/期刊** | 完整收录顶会/顶刊（如 CVPR 2024, NeurIPS 2023, IEEE TPAMI） |
| 6 | **研究问题** | 具体攻克的关键技术痛点（拒绝泛泛的“提高精度”） |
| 7 | **核心方法** | 理论框架、网络骨架、算法机制、数学公式或损失函数核心 |
| 8 | **主要创新点** | 1-2 点本质创新（如新型自注意力机制、因果去偏模块、解耦表征等） |
| 9 | **数据集/实验设置** | Benchmark 规模、硬件设置、评估协议（未提供写“文献未说明”） |
| 10 | **关键实验结果** | 核心量化指标对比（如 FID、mAP、BLEU、SOTA 提升幅度） |
| 11 | **方法优点** | 相比前序工作的本质优势（效率、泛化性、理论严谨度） |
| 12 | **方法局限** | 算力开销大、依赖特定先验、对噪声敏感、未做域泛化等缺陷 |
| 13 | **与本研究方向的关系** | 属于基础骨干、对照 Baseline、上游技术还是直接竞争方案 |
| 14 | **是否建议重点汇报** | 是 / 否 |
| 15 | **推荐汇报理由** | 为什么组会/答辩导师会关心本篇（理论启发/最新 SOTA/缺陷典型） |
| 16 | **证据出处 (Evidence)** | 对应本地 PDF 文件名与确切页码范围（如 '[01]_paper.pdf, pp. 4-5'），未提及填'文献未说明' |

---

### 第三阶段：编纂 7 大章节方向调研报告 (Survey Report)

遵循学术文献综述的高级范式（详见 `references/report-template.md`），包含以下 7 大章节：

1. **研究方向概述**：
   - 本质问题定义（数学形式化或物理意义）。
   - 核心重要性与理论/工业价值。
   - 典型实际应用落地场景。
2. **研究发展脉络**：
   - 早期开拓性方法（Rule-based / 传统统计 / 经典深度网络）。
   - 中期过渡性改进与技术演进节点。
   - 当前最新主流方法与范式演变。
3. **方法分类与体系**：
   - 自动归纳为 3-5 类方法体系。
   - 逐类阐明：核心思想、代表性论文、优势与根本局限。
4. **代表性文献深度剖析 (5-8 篇重点精读)**：
   - 针对最具启发性的 5-8 篇文献逐篇拆解：研究问题、核心算法设计、核心创新点、实验证据与实证缺陷。
5. **横向文献对比与认知总结**：
   - 方法间架构与性能维度的对比矩阵。
   - 当前学术界**已经解决**的核心问题。
   - 当前学术界**依然未解决/悬而未决**的技术难点。
6. **核心挑战与未来博士研究切入点**：
   - 总结 3-5 个具有学术价值的长远开放性挑战。
   - 给出 2-3 个具体、可行、创新度足且可落地的**博士生选题/开题切入点**（含研究动机与技术路线初设）。
7. **总结 (Executive Summary)**：
   - 用一段精炼且深刻的话概括该方向的核心研究逻辑与技术演进闭环。

---

### 第四阶段：生成组会/开题汇报 PPT (Marp Presentation Deck)

生成可直接在 VS Code (Marp 插件) 或 Marp CLI 中渲染成 PPTX/PDF 的 Markdown 幻灯片代码（详见 `references/ppt-template.md`）。
- **页面规格**：16:9 比例，采用干净高雅的学术主题。
- **页面容量**：15-20 页，覆盖从背景挑战、演进时间线、方法树状图、重点论文剖析、对比矩阵到开题建议的完整闭环。
- **演讲备注**：关键页面附带 `<!-- Note: ... -->` 演讲者备忘录，指导博士生汇报时的表达重点与应对导师提问技巧。

---

## 检查与验收规范 (Verification Checklist)

在交付前，必须核查以下 7 项指标：
- [ ] **真实证据链强制门禁（P0 铁律）**：必须运行并通过 `python scripts/verify_grounding.py <matrix.md> --pdf-dir <dir>` 证据链门禁核验（PyMuPDF 物理核验页码与正文）。**若门禁 FAIL，则所生成的对比矩阵与调研报告一律作废重做**，严禁向用户交付未通过本地真实 PDF 核验的文献内容！
- [ ] 是否所有实验数据与指标均来自本地真实论文，无任何臆测编造？
- [ ] 未提到的参数、协议或代码是否明确标注了“文献未说明”？
- [ ] 文献阅读表格是否完整涵盖了指定的 16 个字段（含第 16 维证据出处本地 PDF 文件名与确切页码）？
- [ ] 调研报告是否严格满足 7 大章节要求，切入点是否具备博士生学术深度？
- [ ] 幻灯片是否符合 Marp 语法标准并包含演讲提示词？
