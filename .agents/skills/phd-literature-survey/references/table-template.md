# 文献阅读对比表格模板 (Literature Comparison Matrix Template)

本模板规定了文献调研对比表格的标准输出格式。必须严格包含全部 15 个维度字段，严禁省略或合并字段。提供 Markdown 与 LaTeX `booktabs` 三线表双格式。

## 3. 字段规范与填写口径

1. **序号**：连续自增数字，以 `1, 2, ...` 标注。
2. **论文题目**：英文原题。若有知名模型缩写（如 LoRA, DiT, SAM），在题目前以加粗括号标明。
3. **作者**：第一作者姓名，第一机构/知名导师实验室（如 `He et al. (FAIR)`）。
4. **年份**：正式发表或 arXiv 首发年份。
5. **会议/期刊**：发表顶会顶刊全称或简称（如 CVPR, ICML, NeurIPS, ICLR, IEEE TPAMI）。若为预印本，注 `arXiv 预印本 (未检索到录用信息)`。
6. **研究问题**：精准界定技术矛盾点。严禁泛化空洞描述，必须写出本质痛点。
7. **核心方法**：核心理论设计、网络结构、数学优化目标或算法主干。
8. **主要创新点**：提炼最具学术增量的 1-2 点（机理级、公式级或机制级创新）。
9. **数据集/实验设置**：评测所用公开标准数据集、基线模型、硬件算力（未说明项明确填写“文献未说明”）。
10. **关键实验结果**：必须带核心量化指标与提升幅度（严禁仅写“效果显著提升”）。
11. **方法优点**：理论严谨度、推理吞吐、泛化能力、训练稳定性等学术亮点。
12. **方法局限**：算力开销过大、对噪声极敏感、缺乏理论下界保证、在特定长尾场景失效等真实短板。
13. **与本研究方向的关系**：明确其在研究体系中的定位（核心 Baseline / 灵感启发源 / 上游特征提供方 / 竞品方案）。
14. **是否建议重点汇报**：明确标为 **是** 或 **否**。
15. **推荐汇报理由**：从组会讨论价值、创新机理启发度、导师关注焦点三个维度给出充分理由。
