# 学位论文去模型化与反 AIGC 查重规范 (Anti-AIGC Slop Protocol)

本规范专为中国知网 (CNKI)、万方、维普等高校毕业论文 AIGC 疑似度检测系统设计。
大语言模型直接生成的文字具有高度程式化的词汇共现与句式特征，极易被判定为“高风险 AIGC”（疑似度 > 30%）。
本技能在起草和重构章节时，必须强制执行以下六项反 AIGC 铁律。

---

## 1. 绝杀黑名单：严禁出现的“AI 口癖与套话词汇”

| 禁用词汇 (AI Cliché) | 替代严谨科技用语 | 错误示例与重构对比 |
| :--- | :--- | :--- |
| **“毫无疑问” / “显而易见”** | “实验表明” / “由公式 (1) 可推得” | ❌ 毫无疑问，该方法提升巨大。<br>✔ 实验数据表明，该方法在测试集上的平均准确率提高了 4.2%。 |
| **“双刃剑” / “硬币的两面”** | “计算复杂度与表征容量之间的权衡” | ❌ 注意力机制是一把双刃剑。<br>✔ 注意力机制在增强长程依赖捕获能力的同时，引入了平方级的显存开销。 |
| **“深入探讨” / “全面分析”** | “系统性测试” / “开展定量消融实验” | ❌ 本文将对该问题展开深入探讨。<br>✔ 本文针对高维特征退化问题开展了逐级消融对比测试。 |
| **“不可忽视” / “至关重要”** | “是核心制约因子” / “构成了主要瓶颈” | ❌ 显存占用是一个不可忽视的问题。<br>✔ 显存占用直接制约了该模型在嵌入式边缘端的部署可行性。 |
| **“赋能” / “颠覆性” / “革新”** | “优化了” / “改进了” / “提高了...效率” | ❌ 本文提出颠覆性架构为智能体赋能。<br>✔ 本文提出解耦映射结构，有效降低了冗余特征的相关度。 |
| **“综上所述” (频繁作段首)** | “对比上述两类方法可知” / 删去直接论述 | ❌ 综上所述，我们需要更好的模型。<br>✔ 横向对比表明，现有方案在极端分布偏移下均面临收敛失效。 |

## 2. 句式与结构重构规则 (Syntactic Engineering)

1. **破除对仗排比**：
   - AI 极度热衷于生成“不仅...而且...，不仅...更...”、“一方面...另一方面...”等整齐对仗句。
   - **重构要求**：打破对称性，强制穿插长短句。采用“因果驱动句”和“条件从句”（如“鉴于...，为避免...，本文设计了...”）。
2. **强化被动式与客观陈述语态**：
   - 减少第一人称“我们认为”、“我们发现”。
   - 采用国际主流科技文体：“实验结果表明”、“由表 4-1 数据可知”、“经矩阵正交变换后”。
3. **数据紧随论点，禁止空洞夸赞**：
   - 严禁出现没有具体数据支撑的副词（如“大幅提升”、“极其优越”）。
   - 每次提出观点，下一句必须紧跟量化支撑：“...指标降低了 14.3\% ($p < 0.01$)”。
4. **嵌入特定领域的数学符号与物理量纲**：
   - 纯文字描述最容易被判定为 AIGC；
   - 频繁穿插具体数学符号（$\mathcal{O}(N \log N)$, $\lambda \in [0, 1]$, $\mathbb{E}_{x \sim p_{data}}$），AI 检测工具会将公式密集的段落判定为高学术密度人工撰写文本。
