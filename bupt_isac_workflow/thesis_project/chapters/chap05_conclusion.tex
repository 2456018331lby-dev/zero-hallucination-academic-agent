\chapter{总结与展望}
\label{chap:conclusion}

\section{全文工作总结}
低空智联网作为支撑低空经济安全高效运转的数字中枢，对低空目标的实时连续感知与宽带数据交互提出了严苛的协同要求。本文针对低空无人机系统面临的空地强多径衰落、多普勒扩展以及通感资源竞争等关键理论矛盾，系统性开展了通感一体化波形联合设计与感知先验辅助资源管理技术研究，取得的主要成果总结如下：
\begin{enumerate}
  \item \textbf{建立了面向低空立体空域的空地多载波通感一体化系统模型}：形式化推导了下行多用户通信信干噪比表达式与雷达目标多维参数估计的克拉美罗下界（CRB）闭式矩阵，严谨刻画了发射基带协方差矩阵对通信容量与感知精度的双重映射关系。
  \item \textbf{提出了兼顾 CRB 极小化与容量最大化的 Pareto 最优多载波波形设计机制}：揭示了双功能波形在频域子载波上的功率分配竞争规律，证明了感知测距对边缘子载波的高灵敏度偏好，并通过矩阵提升半正定松弛技术实现了非凸波束赋形问题的高效多项式求解。
  \item \textbf{构建了感知先验引导的无人机动态轨迹规划与快速波束跟踪闭环}：借助雷达回波扩展卡尔曼滤波输出的后验位置与航向速度状态，替代传统盲搜开销，在满足无人机物理动力学与防撞硬约束下实现了通感协同增益的最大化。
  \item \textbf{设计了基于 SCA-BCD 的交替优化求解框架并完成理论收敛性证明}：在数学上严格证明了算法目标函数序列的单调非减收敛性，给出了低阶多项式计算复杂度边界，并建立了标准化的学术脚手架评测基准。
\end{enumerate}

\section{未来研究方向展望}
结合未来 6G 网络演进趋势与低空产业实际发展需求，后续研究工作可在以下方向进一步拓展：
\begin{enumerate}
  \item \textbf{近场空电磁模型与超大规模天线阵列（XL-MIMO）扩展}：当基站采用超大规模天线阵列时，低空无人机往往处于辐射近场区域，需进一步探索球状波前模型下的距离-角度联合聚焦感知与非平稳波束赋形设计。
  \item \textbf{全双工自干扰抑制与低成本硬件损伤建模}：研究收发共用孔径下的射频模拟与数字域自干扰联合消除技术，评估功率放大器非线性失真与量化相移误差对通感一体波形正交性的影响规律。
  \item \textbf{真实空域复杂信道实测与工程验证}：结合低空飞行测试平台采集的三维空间信道冲激响应与实测雷达散射截面积，完成算法的半实物硬件加速验证与试验网外场评测。
\end{enumerate}
